怎么用

      
    
        
  1. 网址造源：粘贴小说站网址 → 点「开始生成」。程序会自动找搜索入口、识别书籍列表、详情页、目录、正文，并生成 Legado 规则。
    2. 
        
  2. 生成后可以点「真机校验」，用真实网络把搜索→详情→目录→正文跑一遍，看每一环是否通。
    3. 
        
  3. 满意后「保存到书源库」，在书源管理里点「导出全部」得到 JSON 文件。
    4. 
        
  4. 把 JSON 文件传到手机，在「阅读」APP → 书源管理 → 右上角 → 本地导入，即可使用。
    5.

语法含义例子

        
          
class.X.n按 class 取第 n 个（-1 为最后一个）class.row.-1@tag.div!0

          
tag.X.n按标签名 + class 取tag.div.book_other.1@text

          
id.X / text.X按 id / 文本内容取id.content@text

          
@text/@href/@src/@html取文本 / 链接 / 图片 / 内部 HTMLdt@a@href

          
@css: / @XPath: / @json:CSS 选择器 / XPath / JSONPath@css:#content@html

          
##正则##替换正则净化（循环替换）h1@text##\\[.+\\]

          
&& / || / %%合并 / 取第一个有值 / 交替取a@text&&b@text

          
{{key}} {{page}}搜索关键字 / 页码/search.php?q={{key}}&p={{page}}

          
!n / [n:m]排除第 n 个 / 取区间tag.li!0@text

        
      

      
常见问题

      
    
        
  • 搜索不到：站点可能需要 POST 搜索、需要 cookie，或用了 Cloudflare 之类防护；可在编辑里手动改 searchUrl。
    • 
        
  • 站点要 JS 才能出内容：用「启动桌面客户端.bat」启动，程序会用隐藏浏览器窗口渲染一遍；生成页有「JS 渲染兜底」开关，「规则调试」里可对比渲染前后差异。
    • 
        
  • 正文空白：多为字体加密或图片章节，需要手动编写 @js: 规则。
    • 
        
  • 乱码：程序会自动识别 gbk/gb18030/big5；若仍乱码，可在请求头里指定 charset。
    • 
        
  • 书源失效了：在书源管理里点「校验」，看是搜索、详情、目录还是正文哪一环断了，再对照站点现状改规则。
